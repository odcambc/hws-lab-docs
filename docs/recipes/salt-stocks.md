## Potassium acetate solution - 100 mL

| Component             |  Volume |
| --------------------- | ------: |
| 5 M potassium acetate |   60 mL |
| Glacial acetic acid   | 11.5 mL |
| Water                 | 28.5 mL |

- **sterilization:** Autoclaving
- **storage:** Room temperature
