# Addgene

Addgene orders require a non-catalog purchasing workflow.

1. Find the required construct on Addgene.
2. Submit a **non-catalog order** for the construct.
3. Biochemistry Purchasing will place the order and handle administrative stuff.
4. Watch for forwarded documents requiring your signature and complete them.
5. Hannah should get an email to approve it.

As always, ask Biochemistry Purchasing if anything is unclear.
