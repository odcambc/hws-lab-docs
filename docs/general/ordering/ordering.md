# Ordering and receiving

## Quick guide

| What are you ordering?                                    | What to do                                                               |
| --------------------------------------------------------- | ------------------------------------------------------------------------ |
| Pens, printer paper, notebooks, or similar basics         | Check the Biochemistry office stock room first                           |
| Department-managed office supplies, such as printer toner | Order through the Biochemistry department using program ID `PG000019893` |
| Cleaning supplies, paper towels, or similar lab supplies  | Order through [MDS Core Stock](#mds)                                     |
| A routine research item costing less than $1,000          | Place the order using the current funding allocation                     |
| An item costing $1,000 or more                            | Check with someone on Slack before purchasing                            |
| Plasmidsaurus sequencing                                  | Follow the [standing-PO workflow](#sequencing)                           |
| An Addgene construct                                      | Follow the [non-catalog workflow](#addgene)                              |
| Anything unclear                                          | Ask on Slack or contact Biochemistry Purchasing                          |

[Biochemistry purchasing intranet](https://uwprod.sharepoint.com/sites/biochem/purchasing)

## Receiving deliveries

### Non-chemical items

Let whoever ordered it know it arrived. If it requires a particular temperature, make sure you put it there.

### Chemicals ordered through ChemManager

These packages should arrive with inventory barcodes already attached.

1. Open ChemManager and select **Receiving Actions**.
2. Find the ordered item.
3. Receive the container using the barcode attached to that specific
   container.
4. Store it and let whoever ordered it know it arrived.

### Chemicals ordered outside ChemManager

Create an inventory container record before storing the item:

1. Open **Material Search** in ChemManager.
2. Search for the compound. Searching by CAS number is usually the most
   specific method.
3. Select **Add Container**.
4. Grab a barcode from one of the sheets of them and put it on the container.
5. Enter the container details and assign its barcode.
6. Store it and let whoever ordered it know it arrived.
