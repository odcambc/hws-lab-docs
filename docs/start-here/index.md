# Using this site

The site groups lab documentation by its purpose:

- **Protocols** describe experimental procedures.
- **Recipes** define shared solutions, buffers, and media.
- **Instruments** cover training, operation, and maintenance.
- **General lab information** covers administrative and routine lab procedures.

## Using a protocol

Check the status panel at the top of the page for the status and
last updated time. Draft procedures aren't complete.

## Improving a protocol

Propose a change with a pull request and request a review:
see [contributing](contributing.md).
