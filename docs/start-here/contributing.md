# Contributing

The site is stored as Markdown in Git so changes can be reviewed and traced.

## Make a small correction

1. Open the relevant Markdown file.
2. Make your change.
3. Explain why in the commit or pull request.
4. Ask the page owner to review it.

## Add a protocol

Copy `docs/protocols/_template.md`, place it in the appropriate section, and
replace every placeholder.

## Review checklist

- [ ] Title and purpose are unambiguous
- [ ] Owner, status, version, and review dates are present
- [ ] Hazards and required training are included
- [ ] Materials include concentrations and identifiers where needed
- [ ] Steps specify time, temperature, and speed
- [ ] Troubleshooting notes or citations are included if necessary
